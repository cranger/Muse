cranger muse

A personal automation that connects a private AI assistant to Google Chat. It periodically reads the owner's Chat spaces through the Google Chat API and surfaces reminders, direct questions, and time-sensitive family or school updates. It is built for a single user and is not offered as a service to anyone else.

What it does

  • Reads messages in the owner's Google Chat spaces (read-only).
  • Highlights reminders, requests, and deadlines addressed to the owner.
  • Never sends messages without the owner's explicit instruction.
