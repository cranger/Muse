Privacy Policy

Last updated: October 2, 2026

cranger muse is a personal automation built for a single user. This policy describes how it handles Google user data.

Data accessed

The app accesses the owner's Google Chat data through the Google Chat API, using the following scopes: reading chat spaces, messages, memberships, and message reactions, plus basic profile information. Access is granted by the owner through Google's OAuth consent screen.

How data is used

Chat data is used solely to surface reminders, direct questions, and time-sensitive updates to the owner. The app does not send messages, modify chats, or take any other action without the owner's explicit instruction.

Data storage and sharing

  • OAuth tokens are stored on the owner's private home server and are never shared with any third party.
  • Message content is processed in memory to produce summaries for the owner and is not sold, rented, or disclosed to anyone else.
  • No analytics, advertising, or tracking is performed.

Data retention and deletion

The owner may revoke the app's access at any time from their Google account permissions page. Revoking access immediately stops all data collection; stored tokens can be deleted from the home server on request.

Contact

Questions about this policy can be directed to the app owner through the Google Cloud project associated with this app.
