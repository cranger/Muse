web-assistant

A personal web dashboard that runs on the owner's home server. It connects to the owner's Google account to put email, calendar, and tasks in one place. It is built for a single user and is not offered as a service to anyone else.

What it does

  • Reads the owner's Gmail to triage the inbox, with AI-assisted categorization and summaries of message threads.
  • Lets the owner act on mail from the dashboard: archive, report spam, star, and send replies they compose themselves.
  • Shows an agenda view of the owner's Google Calendar events.
  • Manages the owner's Google Tasks lists, including completing tasks.
  • Shows a stock ticker powered by the owner's own Apps Script, which reads quote data from the owner's spreadsheets.
